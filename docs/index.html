The first finding, from the live stream

Bikes ride into Manhattan, and stay there

Morning commuters pick up bikes near home and dock them near work. By midday the residential stations are drained, and they stay empty until people ride home.

These 15 sat empty for the entire 30 minute window. Each mark is one dock, and every one is empty. The pattern is the commute: residential Queens, the Bronx and upper Manhattan drain into Midtown.

How it works

Two lanes into one warehouse

A streaming lane for live dock status, a batch lane for monthly ride history, and dbt turning both into tested answers.

Design decisions

Every choice has a reason

Each one came from a real problem in the data.

Rerunning a load

Idempotent by design

A composite key (station_id, last_reported) plus on conflict do nothing. A rerun inserts exactly 0 rows.

Fake 1970 timestamps

Fix the cause

54 stations reported Jan 2, 1970. The real reason was is_installed = false, so that is what the filter checks.

1,700 rows a minute

Duplicate ≠ redundant

Stations send heartbeats when nothing changed. The producer compares each station's state and only sends real changes.

Crash mid batch

Exactly once, in effect

The consumer commits Kafka offsets only after the database transaction. Replays are harmless because every insert is idempotent.

Two CSV schemas

Normalize at the edge

Pre 2021 files use different columns and no ride id. One function maps both, so nothing downstream cares which year it is.

Reloading a month

Atomic replace

Delete the month and insert it again in one transaction. Readers never see half a month, and Airflow can retry safely.

Snapshots, not durations

Spells with LEAD()

Each stored state lasts until the station's next row. Spells are split at hour boundaries to get minutes empty per hour.

Two kinds of station id

Join on the right key

Trip files use the station's short_name, not the live feed's station_id. Locations come from ride coordinates, by median.

Pipeline outages

No invented spells

Open spells end where the data ends, and none lasts over 12 hours, so a laptop going to sleep can't fake a 3 day empty station.
